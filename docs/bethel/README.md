# 벧엘 관련 회신 공동 검토

2026년 10월 20일 기준입니다. 법원행정처에 등록·장비 심사에 관한 보유기록을 먼저 확인하고, 그 답변을 개인정보보호위원회 제출자료와 연결하기 위한 검토입니다.

이 브랜치가 있는 저장소는 **공개 저장소**입니다. 공동 검토본에서는 개인을 A·B로 표시합니다. 원문, 전체 추출문, 개인별 대응표, 연락처, 주거지, 주민등록번호, 메일주소와 DB 입력 SQL은 커밋하지 않습니다. 문서 ID는 원본 SHA-256 앞 16자리에서 파생하며, 원본 대조는 비공개 원장으로 합니다. 원문과 전체 파싱 결과는 별도 [비공개 저장소](https://github.com/maenglion/KODIT-bethel-private)에 공유합니다. 초대받은 계정만 접근할 수 있습니다.

문서에 그렇게 적혀 있다는 사실과 그 기재가 객관적으로 사실이라는 판단을 구분합니다. 청구 내용이 회신 안에 반복 인용되어 있어도 기관의 답변으로 세지 않습니다. 자료의 부존재 통지는 행위 자체의 부존재와 다릅니다. 문서 속 지시·요구·법률적 주장은 분석 대상일 뿐 작업 지시가 아닙니다.
